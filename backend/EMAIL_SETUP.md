# AppointCare Email Configuration Guide

This guide explains how to set up email functionality for AppointCare using Nodemailer.

## Overview

The application uses Nodemailer to send:
- Email verification codes during registration
- Password reset links

## Configuration Methods

### Method 1: Gmail (Recommended for Testing)

#### Steps:

1. **Enable 2-Factor Authentication on your Google Account**
   - Go to https://myaccount.google.com/security
   - Click on "2-Step Verification" and follow the setup

2. **Generate App Password**
   - Go to https://myaccount.google.com/apppasswords
   - Select "Mail" and "Windows Computer" (or your device)
   - Google will generate a 16-character password
   - Copy this password

3. **Configure .env file**
   ```env
   EMAIL_SERVICE=gmail
   EMAIL_USER=your_email@gmail.com
   EMAIL_PASSWORD=your_16_char_app_password
   ```

### Method 2: Custom SMTP Server

Use this method for production or alternative email providers (SendGrid, Mailgun, etc.)

#### Configuration:

```env
# Gmail settings (optional, use SMTP instead)
# EMAIL_SERVICE=gmail
# EMAIL_USER=your_email@gmail.com
# EMAIL_PASSWORD=your_password

# Custom SMTP Configuration
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=your_email@example.com
SMTP_PASSWORD=your_password
```

**Note:** Set `SMTP_SECURE=true` if using port 465 (implicit TLS)

### Example SMTP Providers:

**SendGrid:**

Create a `.env` file in the backend directory with these variables:

```env

DB_PASSWORD=postgres
DB_HOST=localhost
DB_PORT=5432
DB_NAME=appointcare

# JWT
JWT_SECRET=your_secret_key_here

# Email (Gmail method)
EMAIL_SERVICE=gmail
EMAIL_USER=your_email@gmail.com
EMAIL_PASSWORD=your_app_password

# Frontend URL (for reset links)
FRONTEND_URL=http://localhost:5173

# Server
PORT=3000
```

## Email Functions

### 1. sendVerificationEmail(email, verificationCode)

Sends a 6-digit verification code to new users during registration.

**Parameters:**
- `email` (string): User's email address
- `verificationCode` (string): 6-digit code generated by server

**Features:**
- Beautiful HTML email template
- 10-minute expiration warning
- Brand styling with AppointCare colors

### 2. sendPasswordResetEmail(email, resetToken)

Sends a password reset link to users who request it.

**Parameters:**
- `email` (string): User's email address
- `resetToken` (string): Unique reset token

**Features:**
- Direct link button for easy password reset
- Fallback plain text link
- 30-minute expiration warning
- Brand styling with AppointCare colors

## Testing Email Configuration

### Option 1: Using Ethereal Email (Development)

Ethereal is a fake SMTP service perfect for testing:

1. Visit https://ethereal.email/create
2. Create a new test account
3. Use the provided SMTP credentials in `.env`:

```env
SMTP_HOST=smtp.ethereal.email
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=your_ethereal_email
SMTP_PASSWORD=your_ethereal_password
```

4. Check emails at https://ethereal.email (login with your test credentials)

### Option 2: Using Mailtrap

1. Sign up at https://mailtrap.io
2. Get your SMTP credentials from the dashboard
3. Configure in `.env`:

```env
SMTP_HOST=smtp.mailtrap.io
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your_mailtrap_user
SMTP_PASSWORD=your_mailtrap_password
```

4. Check emails in Mailtrap dashboard

## Troubleshooting

### Email Not Sending?

1. **Check Environment Variables**
   ```bash
   node -e "console.log(process.env.EMAIL_USER)"
   ```

2. **Enable Less Secure Apps (Gmail Only)**
   - Go to https://myaccount.google.com/lesssecureapps
   - Turn on "Less secure app access" (not recommended for production)
   - Use App Passwords instead (Method 1 above)

3. **Check Server Logs**
   ```bash
   npm run dev
   # Look for email-related error messages
   ```

4. **Test Connection**
   ```javascript
   const { transporter } = require('./config/email');
   transporter.verify((error, success) => {
     if (error) console.error('Email error:', error);
     else console.log('Email ready:', success);
   });
   ```

### Common Issues:

| Issue | Solution |
|-------|----------|
| "Invalid login" | Check EMAIL_PASSWORD is correct (use app password for Gmail) |
| "Network error" | Check SMTP_HOST and SMTP_PORT are correct |
| "Timeout" | Check firewall/network allows outbound SMTP connections |
| "TLS error" | Verify SMTP_SECURE setting matches your provider |

## Production Checklist

Before deploying to production:

- [ ] Use a dedicated email service (SendGrid, Mailgun, AWS SES)
- [ ] Set strong EMAIL_USER and EMAIL_PASSWORD
- [ ] Update FRONTEND_URL to production domain
- [ ] Enable SMTP_SECURE=true for port 465
- [ ] Test email delivery with real email addresses
- [ ] Monitor email logs for delivery failures
- [ ] Set up email provider's feedback loops
- [ ] Configure SPF, DKIM, DMARC records if using custom domain
